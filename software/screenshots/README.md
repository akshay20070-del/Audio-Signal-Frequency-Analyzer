## How to Take Screenshots

- **Windows:** Press `Win + Shift + S` to use Snipping Tool, or `Print Screen`.
- **macOS:** Press `Cmd + Shift + 4`.
- **Linux:** Use `gnome-screenshot` or `scrot`.

Save screenshots here and update the main `README.md` to link them.
